🚀 项目路演：AI 核心产品

GlobalPath Agent

—— 低成本出国专业顾问

针对低成本出国信息过载、筛选难的痛点。通过双栏 MVP 页面，左侧采集个人预算与背景，右侧自动匹配并推送精准路径，解决手动查询官网的繁琐过程。

FileTidy AI

—— 多模态媒体自动化管家

一键整理本地混乱文件。进阶方向为引入视觉大模型，实现照片、视频的内容自动标记与智能分类，并计划打通手机端与 iCloud 的全平台同步管理。

📝 结业复盘：重点心得

  • AI 深度协作： 学会了在工具报错时询问 Gemini 获取底层逻辑指导，跳出自动化陷阱。
  • 工程闭环能力： 掌握了在 Trae 建立 HTML 后，手动同步至 GitHub Desktop 并通过 Vercel 发布的标准流程。
  • 规范意识： 深刻理解了项目命名规范（kebab-case）对云端构建的重要性，成功应对了平台风控与环境冲突。
